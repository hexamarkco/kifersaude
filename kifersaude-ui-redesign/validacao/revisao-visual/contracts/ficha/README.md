# Ficha completa de contrato

A ficha real `ContractDetails` foi comparada com as referências da [versão desktop](../../../../references/desktop/extra--contratos-ficha.png) e [versão mobile](../../../../references/mobile/extra--contratos-ficha.png). A prévia usa somente dados sintéticos. A página mantém contratos, ações e informações reais, sem alterar regras comerciais.

O rótulo da seção recolhível foi reduzido para **Mais informações do contrato** nas apresentações de página e drawer. Em 320 px, o rótulo cabe no acionador; em todas as larguras testadas, o documento permaneceu dentro da viewport. A rota autenticada redirecionou para autenticação sem sessão local disponível, então a comparação com o shell real continua pendente.
